Building TimeLight Map 1.5.0 from source
========================================

You need:
  - the .NET SDK, version 9 or later
  - a MeitouClient 0.24.x install (the release is built against 0.24.0): the folder that holds MeitouClient.dll (the build reads the game's assemblies from
    there as references; nothing of the game is copied into the mod)

Build:

    dotnet build -c Release -p:GameDir=<folder that holds MeitouClient.dll>

The mod folder is written to  out/TimeLightMap/  (TimeLightMap.mod, meitou.json, Meitou.Tests.dll).
Copy it into <Kenshi>/mods/. To write it elsewhere: add  -p:PackageDir=<folder>

The build is deterministic: the same sources, the same .NET SDK version and the same game assemblies give the same
DLL, byte for byte, whether the sources come from a git clone or from the source zip (.gitattributes keeps LF line
endings; SourceLink is off). The 1.5.0 release DLL was built with the .NET SDK 9.0.321 on Linux against MeitouClient
0.24.0; another SDK version builds a working DLL with different bytes.

Checks (the pure code: corners, sizes, the config file, layers, label and place layouts, routes, the round map, keys;
no game install needed):

    cd checks
    dotnet run -c Release          (exit code 0 = every check passed)

    dotnet run -c Release -- --write-sample ../package/timelight-map.cfg.sample
                                   writes the sample config file from MapPrefs.Sample

Files:

    TimeLightMap.csproj        the project; read its comments for why it references the game's own framework assemblies
                               and why the assembly is named Meitou.Tests
    Entry.cs                   the mod's entry point and its Harmony patches
    Commands.cs                the 'topcam' console command
    Settings.cs                the settings page (Settings > Mods), topcam save, and the hotkeys
    TopCam.cs                  the map picture: the second scene pass, the copy onto the screen, the commands
    Marks.cs                   what is drawn on the picture (dots, names, routes, hurt rings, labels, cone, scale, north)
                               and the HUD side
    MapMath.cs                 the view arithmetic, the eased view, the label and place layouts, the route plan, the round
                               map's geometry (no game types: testable on its own)
    MapPrefs.cs                the options: words, defaults, the config file, the quality presets, key names (no game types)
    checks/                    the console checks of MapMath.cs and MapPrefs.cs
    package/meitou.json        the code mod manifest
    package/TimeLightMap.mod   an empty game data file (the game finds a mod folder by its .mod file)
    package/make-mod-file.ps1  writes TimeLightMap.mod
    package/timelight-map.cfg.sample   the sample config file (the same text as MapPrefs.Sample)
    README.txt                 the players' manual
    CHANGELOG.md               what changed in each version
    LICENSE                    the GNU General Public License, version 3
